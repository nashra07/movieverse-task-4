# MovieVerse - Task 4

## ApexPlanet Web Development Internship

### Project Overview

MovieVerse is a responsive movie discovery website developed as Task 4 of the ApexPlanet Web Development Internship.

### Features

- Responsive movie website
- Movie search
- Genre filtering
- Price sorting
- Rating sorting
- Add movies to watchlist
- Remove movies from watchlist
- localStorage for saving watchlist
- Responsive layout
- Navigation sections
- Contact section

### Technologies Used

- HTML5
- CSS3
- JavaScript
- localStorage
